# Agent Reference

This kit keeps no reference of its own here: each thing has one place, so
nothing is said twice and goes stale.

- **A queued task** — its shape and the `SliceChangedPayload` fields: `lib/prompt.md`.
- **How to build a slice** — conventions, file layout, the rules `slice.json` doesn't state: `.build-kit/CLAUDE.md` and the `build-*` skills.
- **Traps this kit has already paid for** — written by hand, read before every slice: `.build-kit/LEARNED.md`.
- **What the loop learns in this project** — generated by the CLI from `npx @eventmodelers/cli learn`, never edited by hand: `.build-kit/AGENTS.md`.
- **The board's API** — the shared `learn-eventmodelers-api` skill.
